НТО — демонстрация высшего уровня

1. Откройте проект в Unity 6000.6.8f1.
2. В Assets/Resources/incidents.json исходно 12 событий. Запустите игру и проверьте счётчик заданий 1/12.
3. Остановите Play. Замените Assets/Resources/incidents.json содержимым NTO_Demonstration/incidents_after.json.
4. Запустите Play: счётчик 1/13, дополнительная авария шлюза станет 13-м событием. C# скрипты НЕ изменяются.
5. Для проверки ошибочных данных в Unity выберите меню Protocol 03:17 / NTO / Validate Demo Data. Оно проверит исходные, изменённые и ошибочные данные без изменения игры.
6. Для демонстрации отказоустойчивости при запуске замените incidents.json на incidents_invalid.json: игра не падает, выводит ошибку конфигурации и не начинает смену. Верните incidents_before.json.
7. Снимите отдельные короткие демонстрации и сохраните исходный/изменённый JSON.

ВАЖНО: существующая сцена создаётся через меню Protocol 03:17 / Create or Rebuild Main Scene. После создания сохраните её, добавьте в Build Profiles и соберите Windows x86_64.
